# 勇者斗恶龙 - 横版冒险游戏

一个基于HTML5 Canvas的2D横版动作RPG游戏，灵感来自经典的勇者斗恶龙系列。

## 游戏特色

### 🎮 游戏玩法
- **横版动作RPG**：经典的2D横版游戏体验
- **10个精心设计的关卡**：从绿色草原到魔王殿堂
- **角色成长系统**：升级、属性提升、经验值系统
- **多样化战斗**：近战攻击 + 范围技能攻击

### 👾 怪物系统
游戏包含5种不同类型的怪物，每种都有独特的属性和AI行为：

1. **史莱姆** (Slime) - 新手怪物，血量低但数量多
2. **哥布林** (Goblin) - 敏捷的小型敌人，攻击频率高
3. **兽人** (Orc) - 中型敌人，平衡的攻防属性
4. **骷髅** (Skeleton) - 快速移动，攻击力较高
5. **恶龙** (Dragon) - 最终BOSS，超高血量和攻击力

### 🗺️ 关卡设计

1. **绿色草原** - 新手教学关卡
2. **森林深处** - 增加平台跳跃元素
3. **山洞入口** - 引入骷髅敌人
4. **地下迷宫** - 复杂的平台布局
5. **熔岩洞穴** - 高难度战斗
6. **冰雪高原** - 环境主题变化
7. **古代遗迹** - 高等级敌人
8. **暗黑城堡** - 接近最终挑战
9. **魔王前厅** - 最终准备
10. **魔王殿堂** - 最终BOSS战

## 🎯 游戏操作

### 基本控制
- **WASD** 或 **方向键** - 角色移动
- **W** 或 **↑** 或 **空格** - 跳跃
- **空格** - 近战攻击
- **E** - 技能攻击（范围伤害）

### 游戏机制
- **血量系统**：受到伤害会减少HP，HP归零游戏结束
- **经验系统**：击败敌人获得经验值，升级提升属性
- **金币系统**：击败敌人获得金币奖励
- **技能冷却**：技能攻击有冷却时间，合理使用
- **关卡进度**：完成当前关卡解锁下一关

3. 开始你的冒险之旅！

## 🛠️ 技术实现

- **HTML5 Canvas** - 游戏渲染引擎
- **原生JavaScript** - 游戏逻辑和物理引擎
- **CSS3** - 用户界面样式
- **面向对象设计** - 清晰的代码结构

### 核心系统
- **游戏引擎**：帧循环、输入处理、碰撞检测
- **物理系统**：重力、跳跃、平台碰撞
- **AI系统**：敌人巡逻、追击、攻击行为
- **粒子系统**：战斗特效、视觉反馈
- **相机系统**：平滑跟随玩家移动

## 🎨 视觉特效

- **粒子效果**：伤害数字、魔法效果、爆炸特效
- **动画系统**：角色和怪物的动画帧
- **UI动画**：血条、经验条的平滑变化
- **环境渲染**：多层背景、云朵动画

## 📈 游戏平衡

### 角色属性成长
- **血量**：每级+20 HP
- **攻击力**：每级+5 攻击力
- **防御力**：每级+2 防御力
- **经验需求**：每级需求经验递增50%

### 怪物等级设计
- 关卡越深，怪物等级越高
- 高等级怪物提供更多经验和金币
- BOSS级怪物拥有特殊的高属性
